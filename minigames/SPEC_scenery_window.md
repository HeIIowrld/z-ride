# 풍경 배경 + 차문 창문 + 렌즈 물방울 — 디자인 재작업 지시서

대상: `minigames/` 만. `games/deadzone`, `server/`(저장소 루트), `android/` 수정 금지. 커밋·푸시 금지.
먼저 읽기: AGENTS.md, minigames/DESIGN_SYSTEM.md, SPEC_raindrop_v3_physics.md, games/raindrop/game.js·physics.js, games/pole-jump/game.js, shared/sketch.js, shared/ply.css.
규칙: UTF-8(BOM 없음), PowerShell Set-Content/Out-File/리다이렉트로 파일 쓰기 금지, 이모지 금지, 외부 라이브러리·이미지 파일 금지(전부 코드로 그림), 설명용 HTML 신규 금지.
물리 규칙(physics.js의 힘·물길·먼지 모델)과 점수·기록 형식은 유지. 이번 작업은 **그림과 화면 구성**.

## 사용자 피드백 (폰으로 직접 플레이)
1. "물방울에 이상한 선이 있다" (꼬리·스케치 선이 지저분함)
2. "배경에 이상한 차트 같은 게 있다" (세로 막대 가로등 + 네모 블록 + 호 한 줄 → 풍경으로 안 보임)
3. "배경을 하늘·산·바다 같은 경관으로. 전봇대 게임도 마찬가지"
4. "물방울 잔상(물길)이 안 보인다"
5. "창문 곡선(지붕 라인)이 더 위에 있어야 한다"
6. "컨셉: 차 문 쪽 창문으로 풍경을 바라보며 물방울을 잡는 것"
7. "물방울은 창문 아래로 넘어가지 못하게. 닿으면 없어지게"
8. "물방울 내부는 빛의 굴절로 풍경이 비친다(볼록 렌즈) + 약간 탁함"
9. "옅어서 잘 안 보이는 먼지도 추가"
10. "밤인지 낮인지 구별, 색도 추가"
11. "디자인을 손 많이 봐 달라. 물방울 게임뿐만 아니라"

## 1. 공용 풍경 모듈 `shared/scenery.js` (신규, 순수 canvas 2D)
`createScenery({ seed })` → `{ update(dt, speedKmh, dir), draw(ctx, x, y, w, h, opts), setTimeOfDay(mode), palette }`
- **시간대**: 'day' | 'dusk' | 'night'. 기본은 기기 로컬 시각(06~17 day, 17~19·05~06 dusk, 그 외 night). `?scene=day|dusk|night` 로 강제(dev 아니어도 허용). dev 패널에 선택 버튼.
- **팔레트(색 추가)**: 
  - day: 하늘 위 #6fb6ff → 아래 #cfe9ff, 먼 산 #7f9fc4, 가까운 산 #4f7a63, 바다 #2f86c9·반짝임 흰색, 들판 #86b86a, 구름 흰색
  - dusk: 하늘 #2b2f77 → #ff8a5c → #ffd08a, 산 #4a3a6e/#2d2748, 바다 #6a4a8c에 주황 반사, 해는 수평선 근처
  - night: 하늘 #070b1f → #1a1840, 별·달, 산 #171c3a/#0d1126, 바다 #0e1a3a에 달빛 길, 먼 마을 불빛(따뜻한 점)
- **레이어(패럴랙스, 뒤→앞)**: 하늘 그라데이션 → 해/달 → 구름(낮)·별(밤) → 먼 산 능선(부드러운 실루엣, 값 노이즈로 생성) → 가까운 언덕 → 지형대(아래 중 하나) → 근경(가드레일·풀·가끔 나무/표지판이 빠르게 지나감)
- **지형대(biome)가 주행 거리에 따라 천천히 바뀜**(크로스페이드, 대략 600~900m마다): 산길(겹겹 능선) / 해안(수평선·파도 줄·등대나 섬 실루엣) / 들판(논밭 줄무늬·농가) / 도시 외곽(낮은 건물 실루엣, 밤엔 창 불빛). 
- 스크롤 속도는 차 속도 비례, 방향은 좌석(dir). 정차면 멈춤(구름만 아주 느리게).
- 비 올 때 옵션 `rain:true`: 전체 채도·대비 살짝 낮추고 먼 산에 안개 띠.
- 모든 도형은 **채운 실루엣 + 부드러운 곡선**. 세로 막대·네모 블록·한 줄짜리 호 같은 추상 도형 금지. 누가 봐도 풍경이어야 함.
- 성능: 레이어별 오프스크린 캐시(폭 2배 타일) 후 drawImage 스크롤. 프레임당 풍경 그리기 2ms 이내 목표.

## 2. 빗방울 캐치 화면 구성 (차 문 창문)
- 세로 화면 전체를 "차 안에서 옆 창문을 보는 장면"으로:
  - **지붕/창틀 윗선 곡선은 화면 맨 위쪽(상단 4~9% 높이)** 에. 지금처럼 화면 중간을 가로지르지 않게.
  - 앞쪽(진행 방향 쪽)에 비스듬한 A필러, 그 옆 바깥에 사이드미러 실루엣 일부. 뒤쪽은 B필러 세로 기둥.
  - **창문 아래 = 도어 벨트라인(창틀 고무 몰딩)**: 유리 영역의 바닥. 그 아래는 도어 트림(어두운 실내, 손잡이·창문 스위치 실루엣, 살짝 스티치 선). HUD 3칸은 도어 트림 위에 놓인 패널처럼.
  - 유리 영역 = 화면 폭의 거의 전부 × 높이의 약 60%. 실내 프레임은 어두운 단색 + 가장자리 하이라이트 한 줄(유리와 확실히 구분).
- 유리 안: shared/scenery 풍경(rain:true)을 **살짝 흐리게**(오프스크린을 1/3 해상도로 그려 확대) → 그 위에 유리 반사 띠(아주 옅은 대각선 2줄) → 물길 → 먼지 → 방울 → 바.
- **유리 영역으로 클립**: 방울·물길·먼지는 유리 밖(필러·도어 트림 위)에 절대 그려지지 않는다.
- **창문 아래로 못 넘어감**: 방울이 벨트라인(창틀 바닥)에 닿는 즉시 사라진다(작은 물 튐 + 놓침 처리, 게이지 반영). 벨트라인 아래로 떨어지는 그림 금지. physics에서도 y ≥ glassBottom 이면 제거. 바는 벨트라인 바로 위, 유리 안.
- 놓친 물 게이지: 벨트라인 몰딩을 따라 차오르는 물선으로 표현(기존 게이지 로직 유지).
- 기존의 세로 막대 가로등·분홍/보라 네모 블록·호 한 줄은 전부 삭제.

## 3. 물방울 그리기 (볼록 렌즈)
- 풍경을 그린 오프스크린 캔버스(선명한 버전) `sceneBuf` 를 매 프레임(또는 2프레임마다) 갱신.
- **큰 방울(r ≥ 5px, 화면에 최대 70개)**: 방울 모양으로 clip → 방울 중심 주변의 넓은 풍경 영역(반경 r×3.5)을 **상하·좌우 뒤집어(180° 회전)** 방울 안에 축소해 drawImage (볼록 렌즈 = 뒤집힌 축소 상). 가장자리로 갈수록 어둡게(방사형 그라데이션 림) → 위쪽에 작은 흰 반사점 1개 + 아래쪽 안쪽에 밝은 초승달(빛이 모이는 쪽) → **탁함**: 흰색 6~12% 반투명 덮기(먼지 먹은 방울은 갈회색 20%).
- **작은 방울(r < 5)**: sceneBuf에서 뒤집힌 위치의 색 1점을 샘플(저해상 1/8 버퍼의 getImageData를 프레임당 1회 읽어 배열로 조회)해 채운 원 + 반사점 1픽셀. 선 없음.
- **미끄러지는 방울**: 진행 방향으로 살짝 늘어난 눈물 모양(매끈한 베지어, 렌즈 채움 동일). **별도의 직선 꼬리·스케치 선·십자·x자 획 전부 삭제.** 붙은 방울도 c자·대시·x 글리프 대신 크기 다른 둥근 방울/타원으로(유리 위 실제 빗방울처럼 불규칙한 크기 분포, 약간 찌그러진 원).
- sketch.js의 흔들리는 선은 물방울·물길·풍경에 쓰지 않는다(차 실내 프레임 윤곽에만 아주 약하게).

## 4. 물길(잔상)을 보이게
- 물길 = 젖은 띠. 폴리라인을 따라 **폭 있는 리본**으로: 띠 안쪽은 풍경이 조금 더 밝고 선명하게 보이게(유리의 흐린 층을 걷어낸 느낌 — 선명한 sceneBuf를 띠 모양으로 clip해 그리거나, 흰색 10~18% + 가장자리 얇은 밝은 선 2줄), wetness에 비례해 투명도. 증발하며 끊기고 **작은 잔류 구슬**이 줄지어 남음.
- 대왕 방울 물길은 폭 2~3배, 12~18초 유지, 눈에 확 띄게. 그 길을 따라 내려오는 방울이 보이도록.
- 기본 수명 6~10초 동안 최소 불투명도 보장(처음 3초는 또렷하게).
- 낮/밤 모두에서 보이는지 확인(밤엔 밝은 띠, 낮엔 살짝 어두운 가장자리 + 밝은 중심).

## 5. 먼지
- **옅은 먼지 막**: 유리 전체에 아주 옅은 얼룩·점(불투명도 3~7%, 잘 안 보이는 수준)이 항상 조금 있음 — 빛 받는 각도에서만 살짝 보이는 느낌(시간에 따라 아주 느리게 명멸). 마찰은 약하게만(μ ×1.3).
- **진한 먼지(터널 등)**: 기존 stick-slip 먼지. 불규칙한 점 군집 + 부드러운 가장자리(갈회색), 불투명도 15~30%. 방울이 지나가면 그 자리 먼지는 닦여 사라지고(깨끗한 줄), 방울은 탁해짐.
- 아이템 입자는 기존대로 반짝이는 입자(먼지와 구분).

## 6. 폴짝 전봇대도 같은 풍경으로
- 배경을 shared/scenery로 교체(선명하게, 흐림 없음). 전봇대·전선·나무·닌자·장애물은 풍경 위 **실루엣+채움**으로: 전봇대는 짙은 갈회색 채움 + 밝은 가장자리, 전선은 얇은 곡선, 땅은 근경 지형대와 이어지게. 낮엔 어두운 실루엣, 밤엔 살짝 밝은 림 + 가로등 불빛.
- 이 게임도 "차 창문으로 본 풍경" 프레임을 같은 방식으로(지붕 윗선은 상단 4~9%, 벨트라인 아래 HUD). 빗방울 캐치와 프레임 그리기 코드를 공용화(`shared/window-frame.js`).
- 위험 구역 빗금, 발판, 판정 로직은 그대로. 흰 선만으로 된 흑백 느낌 제거.

## 8. 검증용 훅 (dev 전용)
