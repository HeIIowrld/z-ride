# 빗방울 캐치 v2 — 지시서 (Codex용)

games/raindrop/game.js만 고친다. **shared/ 폴더와 다른 게임 파일은 건드리지 말 것**(다른 작업이 동시에 수정 중). 흑백 손그림 스타일, 세로 레이아웃, 하단 3칸 HUD, 기록·아이템·모드 규칙, window.__raindrop.getState() 유지.
**인코딩 주의: UTF-8로 저장. PowerShell Set-Content/Out-File 금지. 이모지 금지.**

## 사용자 피드백 (폰으로 직접 플레이)
"물방울 모양이 별로 안 다르고, 너무 느리고, 이벤트가 없다."
원하는 재미: 창문에 이미 여러 방울이 붙어 있다 → 그중 어딘가에서 갑자기 방울이 커진다 → **3단계 크기**가 되면 흘러내리기 시작 → 내려오다 다른 방울과 겹치면 합쳐지며 **더 빨라진다** → 랜덤하고 많은 방울 중 **어떤 걸 받을지 고르는** 재미.

## 1. 시작 상태
- 게임 시작 즉시 창문에 방울 25~40개가 이미 붙어 있음(1단계 위주, 2단계 몇 개).

## 2. 방울 3단계 성장
- 크기 단계: 1단계(작은 점·획), 2단계(작은 원), 3단계(꼬리 달린 눈물 모양). 단계마다 모양이 확실히 다르게 보여야 함.
  - 1단계 모양은 여러 가지(점, 짧은 대시, c/u 곡선, 쉼표, 작은 x 획 등 5종 이상) 랜덤 + 랜덤 회전.
  - 2단계: 크기가 다른 원/타원, 일부는 안쪽에 하이라이트 짧은 호.
  - 3단계: 굵은 윤곽의 눈물 모양 + 아래 꼬리.
- 성장 방식: 매 순간 랜덤한 방울 몇 개가 "부풀기" 시작(빗물이 모임). 부푸는 방울은 살짝 떨리며 커지는 게 보이게(0.5~1.5초에 한 단계). 새 빗방울이 기존 방울 근처에 떨어지면 흡수.
- **3단계 도달 → 흘러내림 시작.**
- 흘러내리던 방울이 다른 방울과 겹치면 흡수 → 크기 증가 + **속도 증가**(흡수할 때마다 +25% 정도, 상한 있음). 흡수 순간 작게 튀는 획 연출.
- 흐름 각도는 기존 규칙(차 속도 + 풍속 + 좌석 방향) 유지.

## 3. 속도·밀도
- 지금보다 훨씬 바쁘게: 이슬비에서도 화면에 동시에 흘러내리는 방울 2~4개, 굵은 비 4~7개, 폭우 7~12개 수준.
- 기본 흐름 속도 1.5~2배.
- 방울 수 상한 300 유지(성능).

## 4. 이벤트 (하단 HUD 이벤트 칸에 이름 표시, 시작 시 상단에 짧은 큰 글씨 알림)
15~25초마다 랜덤으로 하나, 지속 4~8초:
- **돌풍**: 흐르는 방울 전부가 한쪽으로 크게 휘어 흐름(풍속 일시 증가). 화면에 바람 획 몇 줄.
- **터널**: 화면이 어두운 회색 해칭으로 덮였다 개이며, 그동안 새 빗방울이 안 붙음(숨 고르기). 끝나면 몰아서 붙음.
- **물보라**(옆 차가 지나감): 화면 한쪽에서 방울 20~30개가 한꺼번에 튀어 붙음, 일부는 바로 3단계.
- **왕방울**: 아주 큰 방울 하나가 위에서 천천히 흘러 내려오며 지나는 방울을 다 흡수. 받으면 보너스(점수 2배, 테두리 두 줄로 강조).
- **번개**: 화면이 0.2초 하얗게 번쩍인 뒤 3초간 모든 부푸는 속도 2배.
- 폭우 단계 이후엔 이벤트 간격 짧게(10~15초).

## 5. 받는 재미
- 받침(손) 이동은 즉각적으로(지연 줄이기).
- 받을 때 크기별로 다른 피드백: 1단계 작은 "톡", 3단계 큰 "철썩" + 점수 숫자가 튀어 오름.
- 연속으로 받으면 콤보 숫자가 손 위에 잠깐 표시.
