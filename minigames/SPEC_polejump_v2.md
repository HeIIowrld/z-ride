## 1. 속도감·불규칙성
- 화면 스크롤을 더 빠르게 느껴지게: 기본 PX(미터당 픽셀)를 키우고(대략 지금의 1.6~2배), 차 속도 42km/h 기준으로 기둥 하나가 화면을 지나는 데 2~3초 정도.
- 처음부터 간격이 들쭉날쭉: 기둥 간격 35~70m 랜덤(처음 10개는 40~60m), 가끔(10%) 아주 가까운 연속 기둥(25m), 가끔(10%) 먼 간격(80m, 이땐 점프 판정 범위도 같이 늘려 공정하게).
- 리듬 변화: 지형 흔들림(바닥선이 살짝 오르내림), 전선 늘어짐 정도가 기둥마다 다름, 배경 덤불/풀 간격 랜덤, 가끔 먼 산 윤곽 지나감.
- 기둥 높이도 약간씩 다르게(±10%).

## 2. 화면 밖으로 안 나가게
- 지금은 닌자가 기둥과 함께 화면 밖까지 실려 나간 뒤에야 게임오버 → 안 보이는 곳에서 죽어서 억울함.
- 바꿀 것: 캐릭터는 절대 화면 밖으로 나가지 않는다. 화면 뒤쪽 가장자리 안쪽 약 15%에 **위험 구역** 표시(빗금 띠). 닌자가 위험 구역에 들어가면 깜빡이고 경고음, 위험 구역 끝(화면 안쪽 가장자리 선)에 닿는 순간 게임오버 'pushed_out'. 낙하·장애물 연출도 모두 화면 안에서 보이게.
- 카메라: 닌자가 착지한 기둥이 화면의 앞쪽 1/3 지점 근처에 오도록 부드럽게 따라가(lerp). 그래서 다음 기둥이 항상 보이고 판단할 시간이 있음.

## 3. 전봇대 디자인 (지금: 화면 전체 높이의 물결선 두 줄 → 별로)
진짜 전봇대처럼 단순 라인 드로잉으로:
- 기둥: 아래가 약간 굵고 위가 가는 사다리꼴 한 개(외곽선 두 줄, 위아래 막음), 아래는 땅에 박힌 짧은 흙 표시.
- 위쪽: 가로 완목(크로스암) 1~2개 + 위에 작은 애자(작은 둥근 혹) 2~3개, 전선은 완목 끝에서 다음 기둥으로 늘어진 곡선.
- 발판(높이 라인 1·2·3): 기둥 옆으로 튀어나온 짧은 발판 볼트(작은 가로 막대) — 닌자가 서는 자리. 번호 라벨은 아주 작게 또는 없애기.
- 가끔(20%) 기둥에 변압기 통/전단지가 원래 장애물로 붙음(기존 장애물 규칙 그대로, 그림만 새 기둥에 맞게).
- 화면 높이 전체를 차지하지 말고, 지붕/창틀 선 아래 창밖 뷰 안에 들어오는 크기(뷰 높이의 70~85%).

## 4. 가끔 나무
- 기둥 대신 나무가 나오는 경우(약 25%, 10개 이후). 나무도 뛰어 오를 수 있는 "기둥"으로 취급.
- 그림: 줄기(살짝 휜 두 줄) + 위에 구름 모양 잎 덩어리 윤곽선(몇 개의 호), 높이 라인 1·2·3 위치에 옆으로 뻗은 **가지**가 발판 역할.
- 나무 전용 장애물: 새둥지(얽힌 선), 벌집(작은 육각형 덩어리), 다람쥐(작은 꼬리 곡선) 중 랜덤 — 규칙은 기존 장애물과 동일.
- 나무와 나무 사이엔 전선 없음. 전봇대-나무-전봇대 사이도 전선 없음(연속된 전봇대끼리만).
- 하단 HUD 이벤트 칸에 다음 대상이 나무면 "나무", 장애물 있으면 이름 표시.
