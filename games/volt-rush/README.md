# Volt Rush

충전소에서 2~4명이 하는 실시간 게임입니다. 각자 모서리에서 출발해 선을 깔며 가운데 충전기에 먼저 닿으면 그 판을 이깁니다. 지나간 칸은 벽이 됩니다. 3판을 합니다.

## 충전과 연결되는 부분
- **⚡ 예산**: 시작할 때 (목표 SOC − 현재 SOC)로 각자 ⚡를 받습니다(`budgetFor`: 차이×0.8+20, 35~80). 한 칸에 ⚡1, 판이 바뀌어도 다시 채워지지 않습니다.
- **전력 이벤트**: 판(90초) 안에서 30초마다 서지(모든 선 삭제) → 무료 이동 8초 → 정전 5초(화면 가림·실내등 끔) 순서로 터집니다. 배터리 % 기준이 아닌 이유: 10% 오르는 데 초급속은 2~3분, 완속은 1시간이 걸려 충전기마다 들쭉날쭉하기 때문입니다. 배터리 값은 시작할 때 ⚡ 예산에만 씁니다.
- **실내등**: 충전기에 가장 가까운 사람 색. 판을 이기면 GUST.
- 주행 중(P가 아닐 때)에는 차 화면을 가립니다.

## 아이템
루트 시스템이 붙기 전까지 시작할 때 테스트 가방에서 2개씩 줍니다(`ITEMS`, 태그는 `minigames/data/items.json`과 같은 이름).

| 아이템 | 태그 | 효과 |
|---|---|---|
| 절연 장갑 | escape | 다음 한 번, 막힌 칸을 뛰어넘음 |
| 고전압 코일 | attack | 앞쪽 3칸의 남의 선을 끊음 |
| 네온 방패 | defense | 10초 동안 내 선이 안 끊김 |
| 신호 다트 | detection | 충전기까지 가장 짧은 길 표시 |
| 배터리 셀 | part | ⚡+5 |

## 실행
```bash
npm install
npm start        # 기본 포트 8230
npm test
```
- 차 화면: `http://<서버>:8230/` (브라우저에서는 `?mockcar`로 가짜 차 패널)
- 폰: QR 또는 `http://<서버>:8230/p`
- 메시지: 차 화면 `start` `next` `lobby` `kick` `soc{soc,target}`, 폰 `move{dir:U|D|L|R}` `item{id}`
