# PLY 충전소 (충전소 게임 모음)

충전소 게임 4종(Power Castle, Volt Rush, Power Tug, 충전 릴레이)을 한 화면에 모은 모바일 웹 첫 화면입니다. PLY 놀이터(이동 중 게임)와 같은 짜임입니다. 게임 카드마다 두 버튼이 있습니다.

- **큰 화면으로 방 만들기**: 차 화면·태블릿·노트북에서 누르면 그 게임의 방이 열리고 QR이 뜹니다.
- **코드로 참가**: 폰에서 방 코드 5자리로 들어갑니다(보통은 큰 화면의 QR을 찍으면 됩니다).

## 게임 주소
게임 주소는 커밋하지 않는 `links.json`에서 읽습니다(`links.example.json` 참고). 임시 터널 주소는 열 때마다 바뀌기 때문입니다. 파일이 없으면 첫 화면을 연 호스트 이름에 게임 포트(8200·8220·8230·8240)를 붙입니다. 같은 Wi-Fi에서 `http://<맥 IP>:8300`으로 열면 그대로 동작합니다.

## 실행
```bash
npm start   # 기본 포트 8300
npm test
```

## 밖에서 열기 (임시 공개 링크)
각 게임 서버와 이 첫 화면을 Cloudflare 임시 터널(`cloudflared tunnel --url http://localhost:<포트>`)로 하나씩 엽니다. 게임 서버는 `PUBLIC_ORIGIN=<그 게임의 터널 주소>`로 다시 띄워야 QR이 터널 주소를 가리킵니다. 터널 주소를 `links.json`에 적으면 첫 화면 카드가 그 주소로 이어집니다. 임시 터널은 맥이 켜져 있는 동안만 열리고, 다시 열면 주소가 바뀝니다.
