# Power Tug

충전소에서 가족 2~4명이 두 팀으로 나뉘어 **폰을 연타해 가운데 전기를 우리 팀 배터리로 끌어오는** 미니게임이다. 한 판 20초, 2판 먼저 이기면 끝(무승부가 이어지면 5판까지)이라 한 게임이 2분 남짓이다.

## 실행

```bash
cd games/power-tug
npm install
npm start          # 기본 포트 8220
npm test
```

- 차 화면(호스트): `http://<서버>:8220/` — 방을 열고 QR을 보여 준다. 일반 브라우저에서는 `?mockcar`를 붙이면 가짜 차 패널로 연출을 확인할 수 있다.
- 폰: QR이 여는 `/p#코드`. 앱 설치 없이 이름만 쓰면 된다.
- Pleos 허브 목록(`android/pleoshub/src/main/assets/games.json`)에는 에뮬레이터 기준 `http://10.0.2.2:8220/`로 들어 있다.

## 규칙

1. 들어온 순서대로 민트·핑크 팀에 번갈아 들어간다. 폰에서 팀을 바꾸거나, 차 화면에서 팀을 섞을 수 있다. 두 팀 모두 한 명 이상이어야 시작된다.
2. 3초 준비 뒤 20초 동안 폰 화면 전체가 버튼이 된다. 두드릴 때마다 가운데 전기(줄)가 우리 팀 쪽으로 움직인다.
3. 줄이 한쪽 배터리 끝(100%)에 닿거나, 20초가 끝났을 때 줄이 넘어가 있는 팀이 그 판을 이긴다. 정가운데면 무승부.
4. 한 번 연타가 미는 양은 **팀 인원으로 나눈다**. 1:2로 붙어도 1인당 같은 속도면 팽팽하다. 대신 팀원이 손을 놓으면 그만큼 밀린다.
5. 사람 손으로 낼 수 있는 정도(초당 16번)를 넘는 연타는 서버가 버린다.

## 차와 이어지는 부분

| 때 | 요청 |
|---|---|
| 연타 중 한쪽이 앞서면 | 실내등을 앞선 팀 색으로(민트 → `GREEN`, 핑크 → `PURPLE`. 실내등에 민트·핑크가 없어 가장 가까운 색) |
| 판·게임이 끝나면 | 이긴 팀 색 + 바람 `GUST` |
| 대기실로 돌아가면 / 페이지를 닫으면 | 원래대로(`NORMAL`, `reset`) |
| P단이 아니면 | 화면을 가린다 |

바람은 공조가 켜져 있을 때만 바뀐다(허브가 공조를 새로 켜지 않는다).

## 구조

- `game.mjs` 규칙(순수 상태 기계), `server.mjs` HTTP·WebSocket. 폰은 연타를 0.12초마다 모아 `{type:'tap', n}`으로 보내고, 서버는 화면 갱신을 0.08초 간격으로 모아 보낸다.
- 방 코드·토큰 처리, QR, 재접속은 `games/charge-relay`와 같다. 토큰은 URL에 넣지 않는다.

## 참고

공개된 "연타 승부 결과로 실제 충전 방향이 바뀌는" 데모에서 착안했다. 이름·화면·코드는 새로 만들었고, 실제 전력은 옮기지 않는다(점수와 실내 연출만).
