# 전기 도둑 시연 가이드 (11/8 22:00 미팅)

충전소 게임 "전기 도둑"을 Pleos Connect 에뮬레이터와 폰 2~3대로 보여 주는 순서다.

## 한 줄 소개

충전하는 동안 가족 2~4명이 차 안에서 하는 정체 숨기기 게임이다.
**배터리가 5% 오를 때마다 사건이 터지고**, 가족은 카드 합계를 **구간에 딱 맞춰야** 한다. 모자라면 정전, 넘치면 과부하이고 **실제 차 무드등과 바람세기가 바뀐다.**
차 화면은 공개 정보(구간·합계·퓨즈·비상 차단기), 폰은 비밀 정보(역할·손패·단서)를 맡는다. 그래서 Pleos 앱과 폰이 둘 다 필요하다.

## 왜 차에서 해야 하나

| 차가 하는 일 | 폰이 하는 일 |
|---|---|
| 실제 배터리 SOC로 사건 시작(충전이 곧 게임 시계) | 내 역할 확인(꾹 누르는 동안만 보임) |
| 카드 합계만 공개, 누가 뭘 냈는지는 숨김 | 카드 1장 몰래 내기, 한 명 살펴보기 |
| 정전 → 무드등 끄기·바람 1단 / 과부하 → 빨간 불·바람 훅 | 살펴본 결과(나만 보임) |
| 도둑 장난 → 무드등 빨강 또는 바람 훅 | 도둑만: 몰래 장난 고르기 |
| 운전석 비상 차단기(한 판 2번) | 판 내내 쓰는 손패 4장 |
| D로 바꾸면 게임 가리고 실내 원래대로 | 비밀 투표 |

## 준비 (미팅 30분 전)

1. 서버 켜기

   ```bash
   cd ~/dev/z-ride/games/electric-thief && npm install && node server.mjs
   ```

2. 에뮬레이터 켜기(`Pleos_Connect_34`) → 앱 설치·실행

   ```bash
   ~/Library/Android/sdk/platform-tools/adb install -r ~/dev/z-ride/android/pleoshub/build/outputs/apk/debug/pleoshub-debug.apk
   ```

   ```bash
   ~/Library/Android/sdk/platform-tools/adb shell am start -n ai.zride.hub/.HubActivity --es game electric-thief
   ```

3. Virtual Console 열기: `adb forward tcp:8088 tcp:8088` 후 http://127.0.0.1:8088
   - **Battery SOC**를 40% 정도로 낮춘다(95% 이상이면 시작 불가).
   - **HVAC Power**를 On, **Fan Speed**를 3 정도로 둔다(공조가 꺼져 있으면 바람을 건드리지 않는다).
4. 폰은 Mac과 같은 Wi‑Fi에서 차 화면 QR을 찍는다. 폰이 없으면 브라우저 탭 여러 개로 `http://<Mac IP>:8210/` 접속.

> 주의: 서버를 끌 때 `lsof -ti tcp:8210 | xargs kill`을 쓰지 않는다(에뮬레이터도 죽는다). `kill $(lsof -ti tcp:8210 -sTCP:LISTEN)`만 쓴다.

## 시연 순서 (약 5분)

1. **로비**: 차 화면 QR → 폰 3대 입장 → "시작하기".
2. **규칙 화면**: 차·폰에 5단계 규칙. 폰에서 역할 카드를 꾹 눌러 보여 주고 "이해했어요".
3. **충전**: Console에서 SOC를 +5% 올린다 → 사건 1 시작. "충전이 게임 시계"라는 점을 강조.
4. **사건**: 차 화면에 구간(예: 6~8)이 뜬다. 폰에서 손패 4장 중 1장 + 살펴볼 사람 선택. "누가 크게 낼래?"를 말로 맞추게 한다. 도둑 폰에는 "몰래 장난"이 더 보인다.
5. **결과**: 모자라면 정전 → 차 화면이 어두워지고 바람이 1단으로 떨어진다. 넘치면 과부하 → 빨간 불에 바람이 4초 세게. 운전석의 **비상 차단기**를 눌러 되돌려 보인다(결과 화면 15초 안에). 도둑이 장난쳤으면 "누군가 몰래 차를 건드렸어요!".
6. **토론·투표**: 폰의 단서로 이야기하고 비밀 투표. 과반이면 체포.
7. **안전**: Console Gear를 D로 → 게임이 가려지고 무드등·바람이 원래 값으로 돌아온다. 다시 P로 하면 다시 적용된다.

## 보여 줄 기술 포인트

- Pleos Vehicle SDK: `EvBattery` SOC 구독, `Light` 무드등 밝기·색, `HVAC` 바람세기(원래 세기·오토 저장 후 복구).
- 원래 값 저장·복구: 앱이 강제 종료돼도 다음 실행 때 저장한 원래 값으로 되돌린다.
- 주행 제한: AAOS UX 제한 + 기어로 판단, P가 아니면 실내 변경 금지.
- 서버가 꺼져 있으면 앱이 "게임 서버에 연결할 수 없어요" 화면을 띄우고 5초마다 다시 붙는다.

## 알려진 한계

- 공조가 꺼져 있으면 바람 연출이 없다. 시연 전 HVAC Power를 켜 둔다.
- 바람 GUST(과부하·장난)는 브라우저 가짜 차 패널로만 확인했다. 에뮬레이터에서는 정전(1단)과 D·P·뒤로가기 복구까지 확인했다.
- 2명 판은 도둑 없이 "차가 방해꾼"인 협력 모드다(토론·투표 없음).
- 실차 검증은 아직 없다. 에뮬레이터 기준이다.
