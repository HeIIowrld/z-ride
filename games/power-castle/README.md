# Power Castle

충전소에서 2~4명이 하는 대결 게임입니다. 폰 하나가 성 하나입니다. 가운데 발전소에서 내 성으로 전기를 받고, 남의 성 전기를 끌어와 먼저 목표를 채우면 그 판을 이깁니다. 3판 중 2판을 먼저 이기면 최종 승리입니다. 전기도둑을 대신해 허브에 올렸습니다(`games/electric-thief` 폴더는 그대로 둠).

## 진행
1. 로비: 차 화면 QR로 참가.
2. **규칙 화면**: 시작을 누르면 차 화면에 15초 동안 규칙이 뜹니다(`바로 시작`으로 건너뛰기). 폰에는 짧은 요약이 뜹니다.
3. 판(최대 3분): 차례 없이 각자 원할 때 버튼을 누릅니다.

| 행동 | 비용 | 효과 |
|---|---|---|
| 케이블 | ⚡10 | 받는 전기 +0.6/초, 최대 3가닥 |
| 끌어오기 | ⚡8 | 고른 성에서 ⚡15를 빼 옴. 번개가 3초 동안 날아감. 한 번에 하나 |
| 방패 | ⚡6 | 5초 동안 끌어오기 막음 |
| 과충전 | ⚡12 | 10초 동안 받는 전기 2배, 그동안 방패 불가 |

- 1분 30초부터 10초 동안 발전소 폭주(전기 3배).
- 시간이 끝나면 전기가 가장 많은 성이 이깁니다.

## 차와 연결
- **목표**: 시작할 때 (목표 SOC − 현재 SOC)가 40% 이상이면 ⚡150, 아니면 ⚡100. 게임 중에는 배터리 값을 쓰지 않습니다.
- **실내등**: 1등 성 색(시안→GREEN, 핑크→PURPLE, 앰버→YELLOW, 인디고→BLUE). 판을 이기면 GUST.
- 주행 중(P가 아닐 때)에는 차 화면을 가립니다.
- 폰은 나를 노리는 번개가 오면 진동합니다.

## 실행
```bash
npm install
npm start        # 기본 포트 8240
npm test
```
- 차 화면 `http://<서버>:8240/` (브라우저는 `?mockcar`), 폰 `http://<서버>:8240/p`
- 메시지: 차 화면 `start` `skip` `next` `lobby` `kick` `soc{soc}`, 폰 `act{kind: cable|drain|shield|over, target}`
