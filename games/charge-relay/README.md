# 충전 릴레이

충전소에서 가족 2~4명이 폰으로 하는 그림 전달 게임. 앱 설치 없이 웹으로 돌아간다. 게임 서버 계약(`server/openapi.json`·`protocol.json`)과 무관한 독립 폴더다.

## 규칙

1. 큰 화면(차량 화면·노트북)에 QR이 뜨고, 폰 카메라로 찍어 이름만 적으면 들어온다.
2. 한 판에 사람 수만큼 스케치북이 돈다. 게임이 여행 단어를 뽑아 주면 첫 사람이 그리고(75초), 다음 사람은 그림만 보고 맞히고(35초), 그다음 사람은 그 답만 보고 다시 그린다.
3. 다 돌면 큰 화면에서 한 칸씩 공개한다. 그림은 그린 순서대로 다시 그려진다. 폰으로 마음에 드는 칸에 하트를 보낸다(내 칸 제외).
4. 마지막 답이 처음 단어와 같으면 "전달 성공". 가족 전체 점수이고, 하트를 가장 많이 받은 사람이 오늘의 화가다.
5. 2·3·5판 중 고른다. 판이 지날수록 위쪽 충전 게이지가 찬다.

스케치북 b의 s번째 칸은 (b+1+s)번 사람이 채운다. 그래서 2~4명 모두 단어를 본 사람이 다시 맞히지 않는다. 3명이면 그림으로 끝나고, 전달 성공은 마지막 답으로 판정한다.

## 실행

```sh
npm install
npm start          # 8200 포트. 같은 Wi-Fi 폰이 들어올 주소로 QR을 만든다
npm test
```

- 큰 화면: `http://localhost:8200/`
- 폰: QR 촬영, 또는 `/p`에서 방 코드 입력
- QR 주소를 고정하려면 `PUBLIC_ORIGIN=https://example.test npm start`

## 구조

| 파일 | 내용 |
| --- | --- |
| `game.mjs` | 규칙(네트워크·타이머 없는 상태 기계) |
| `words.mjs` | 단어 묶음 |
| `server.mjs` | 방·참가 REST, WebSocket, 시간 초과 처리, 정적 파일 |
| `public/host.*` | 큰 화면 |
| `public/phone.*` | 폰 화면 |
| `public/shared.js` | 그림 그리기·다시 그리기·재접속 |
| `public/qr.js` | 외부 의존성 없는 QR 생성기(`/play/car`와 같은 파일) |

- 방은 메모리에만 있고 3시간 뒤 정리된다. 서버를 재시작하면 판이 사라진다.
- 폰 세션과 그리던 칸은 `localStorage`에 둔다(카메라가 여는 새 탭 대응). 8초 안에 `auth.ok`가 없으면 다시 연결한다.
- 진행 중 단어와 그림은 맡은 사람에게만 보낸다. 그림은 1000×1000 좌표의 획 목록만 받고, 크기를 제한한다.

## 아직 안 된 것

- **충전 게이지는 시연값**이다(30%→80%). 실제 SOC를 받으면 `public/host.js`의 `gauge()`만 바꾸면 된다.
- Google 계정 연결과 Z-RIDE 파티 연동은 없다. 지금은 이름만 적고 들어온다.
- 실물 아이폰 카메라·손가락 드로잉 시험 전이다.
