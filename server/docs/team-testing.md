# 아이폰 팀 테스트용 가상 차량 호스트

2026-11-01. `tools/team-host.mjs`는 서버 통신 시험용 호스트다. 실제 Pleos SDK 차량 신호를 읽지 않고 `SIMULATED_API_CLIENTS` 출처로 P·UX 허용 신호를 2초마다 보낸다. PHONE 세션은 만들지 않아 세 좌석을 Safari 참가자에게 남긴다.

운영자가 별도로 받은 테스트 키를 비공개 환경 변수 `ZRIDE_TEST_ACCESS_KEY`에 넣은 다음 리포의 `server/`에서 실행하면 된다. 키를 명령행·Git·화면 공유·노션에 넣지 않는다.

```sh
node tools/team-host.mjs --base http://afsd.iptime.org:8000 --durationsec 1800 --invite-file ../work/team-invite.private.json
```

- 기본 30분 실행한다. `--durationsec`는 1~86400초를 받는다.
- 초대 파일은 이 리포의 Git 제외된 `work/` 바로 아래 `*.private.json`만 허용한다. URL·roomId·참가 코드·만료 시각·빈 좌석을 기록하며 세션 토큰·테스트 키는 쓰지 않는다. stdout에도 코드·토큰을 출력하지 않는다.
- 폰에서 `/play`를 열고 테스트 키·닉네임·현재 참가 코드·빈 좌석을 입력한다. 좌석 요청은 이 **가상 시험 호스트**가 자동 승인한다. 실제 탑승·좌석 센서 확인이 아니다.
- 참가 코드는 1회용이다. 누군가 사용하거나 발급 후 90초가 되면 새 코드로 파일을 갱신한다. 다음 참가자는 파일의 최신 코드를 전달받아야 한다. 세 좌석이 다 차면 참가 코드는 null로 바뀐다.
- 기본적으로 첫 승인된 폰이 WS에 연결되면 시험 라운드를 시작한다. 운영자가 `--no-auto-start`를 주면 시작 명령을 자동으로 보내지 않는다. 이 도구는 시작 버튼 UI를 제공하지 않는다.
- CLEARED 이후에는 자동으로 다음 웨이브를 시작하지 않는다. 사용자 중지나 lease 문제로 PAUSED가 되면 자동 재개하지 않는다.
- 종료 시 round.pause를 요청하고 연결을 끊어 차량 lease를 닫는다. 초대 파일은 STOPPED·코드 null로 갱신한다. 방과 재고는 SQLite에 남는다. 서버 재시작 후 이 도구가 자동 재접속하지는 않는다.
- 폰 탭을 닫으면 연결이 끊긴다. 현재 서버에는 참가자 탈퇴·자리 반환 API가 없으므로 새 인원으로 반복 시험할 때 새 도구 실행으로 새 방을 만든다.

HTTP 주소는 데모 지점 수집·사격 통신 시험에 사용한다. 아이폰의 실제 GPS와 전송 암호화는 HTTPS/WSS가 필요하다. `/observer`는 별도 관찰키로 같은 방을 골라 확인한다. 가상 호스트 시험을 실제 Pleos 차량 신호 검증 결과와 섞지 않는다.
