# 폰 1인칭 전투 화면 (`/play` 확장)

2026-11-02. 앱 팀(게임 연출) 작업. 서버 계약은 바꾸지 않았다.

## 무엇을 하는가

- `/play`에 승인된 동승자에게 **1인칭 전투 화면 열기** 버튼을 추가한다. 방 상태가 `PLAYING`으로 바뀌면 자동으로 열린다.
- 차량 주변 360°를 1인칭 시야(가로 64°)로 그린다. 좀비는 snapshot의 `zombies[].angleDeg` 위치에 서 있고 `hp/maxHp`를 HP 바로 표시한다.
- 조준 방법
  - **조이스틱(기본)**: 왼쪽 아래 스틱을 좌우로 미는 만큼 회전한다(최대 120°/초). 내 구역의 살아 있는 좀비와 10° 안이면 회전이 느려져 맞추기 쉽다. 모든 기기에서 동작한다.
  - **폰 돌리기 모드**: 버튼을 누른 순간 폰이 향한 방향을 차량 전방 0°로 잡고, 이후 나침반 방향(`deviceorientation`)으로 조준한다. iOS는 탭 안에서 권한을 요청하며 **HTTPS가 필요**하다. 스틱을 만지면 조이스틱 모드로 돌아간다. 시연·체감용.
- 화면을 톡 누르거나 사격 버튼을 누르면 기존 `command('fire', {angleDeg})`로 보낸다. 명중·피해·HP는 **서버 판정**(`stats.lastShot`, `zombies`)만 반영한다. 로컬에서 명중을 만들지 않는다.
- 내 좌석 `sector` 밖은 어둡게 처리하고 사격을 보내지 않는다. 조준점이 살아 있는 좀비의 ±15°(서버 판정 폭) 안이면 빨간색으로 바뀐다.
- `collection.inventory.supplies`가 늘면 **폰에만** 보급품 알림(진동·효과음)을 띄운다. 차량은 소리만 내는 것이 기획이며 차량 앱 담당이다.
- 주행 중(게이트 닫힘)에는 전투 화면에 잠금 문구만 보여 준다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `phone-client/arena.js` | 조준·렌더링·사격 연출. app.js의 전역 상태(`room`, `memberId`, `pending`)와 함수(`command`, `inside`, `gateOpen`, `online`)를 읽기만 한다 |
| `phone-client/arena.css` | 전투 화면·보급품 알림 스타일 |
| `phone-client.mjs` | 위 두 파일을 정적 허용 목록에 추가 |

CSP(`script-src 'self'`, `style-src 'self'`)를 그대로 지키며 외부 폰트·CDN을 쓰지 않는다.
