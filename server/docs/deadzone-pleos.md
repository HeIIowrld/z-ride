# DEADZONE 장소 게임과 Pleos 차량 효과

## 시험 실행

서버에 `ZRIDE_DEADZONE_ORIGIN`으로 팀이 관리하는 DEADZONE origin을 지정한다. 차량 앱을 해당 Z-RIDE 서버에 연결하고 기존 파티 QR을 발급한다. 폰 참가를 차량에서 승인한 뒤 차량 앱에서 DEADZONE 게임을 준비하면 같은 파티의 승인된 폰 화면에 참가 링크가 나타난다. 승인된 폰이 연결된 상태에서 차량의 라운드 시작을 누르고, 폰에서 DEADZONE에 참가해 준비한다. 차량 조명 효과를 사용하려면 차량 화면에서 앰비언트 효과 허용을 선택한다.

## 동작과 현재 범위

- 링크는 차량 파티, 설정된 거점 ID, 임무 실행 ID를 기준으로 관리한다. 거점 미설정 상태는 리허설에 사용할 수 있다. 구체적인 장소별 게임 배정과 도착 자동 선택은 별도 설정이 필요하다.
- 승인된 동승자 중 서버에서 빈 좌석으로 확인한 멤버를 제외한 수로 방을 만든다. 착좌·벨트 신호는 좌석 상태에 대한 단서다. 폰 계정과 좌석은 QR 승인으로 연결한다. 착좌 의미가 검증되지 않은 AVD의 원시값은 계속 UNKNOWN으로 처리한다.
- DEADZONE이 경기 상태를 판정한다. Z-RIDE가 서버의 관전 상태에서 웨이브 클리어를 한 번 감지해 해당 차량 연결에 효과를 보낸다. 앱은 지원 영역의 앰비언트 밝기를 읽고 제한된 범위에서 일시적으로 변경한다. 값이 앱이 설정한 값과 일치할 때 원래 값으로 복구한다.
- 차량 앱은 주차 중 경기 순위와 웨이브, 팀 점수를 표시한다. 주행 제한 시 게임 패널을 숨기고 효과를 중단한다. 서버도 기어 D, UX 제한, stale report에서 효과를 차단한다.
- 현재 DEADZONE은 독립 게임 서버의 방 코드를 사용한다. Z-RIDE 서버에서 링크를 승인 멤버에게만 제공하지만, 링크를 전달받은 제3자의 직접 참가를 막는 DEADZONE 서버 측 서명 티켓은 추가해야 한다. 공조·목표 온도 실행, 실차 제어와 물리 폰 QR 촬영은 미검증이다.

## 차량 화면과 진단

차량 앱을 일반 실행하면 파티 만들기, QR, 참가 승인, 경기 상태만 표시한다. 기본 연결 주소는 팀 HTTPS 서버다. 에뮬레이터에서 다른 서버를 시험할 때는 기존 `serverUrl` 실행 인자를 사용할 수 있다. 디버그 APK에서만 `vehicleDiagnostics=true`로 실행하면 주소·센서 진단·내비 시험 도구를 볼 수 있다.

## 경로 보급품과 공유 차량 수리

1. 기존 Git 지도 카탈로그를 가져온 서버에 차량을 연결한다. 차량 파티를 만들고 동승자 폰을 승인한다.
2. 활성 경로가 있고 최신 차량 위치가 그 경로의 충전소·주유소·주차장 진입점 근처를 지날 때 동승자 폰에서 ‘경로 보급품 찾기’를 누른다. 기억한 네 자리 숫자를 누르면 파티 보급품 한 개를 얻는다. 파티마다 같은 지점에서 한 번 지급한다. 도로망 진입점은 통과 구간 검색에 사용하며, 실제 방문 가능 여부의 현장 확인과는 구분한다.
3. 차량이 P이고 주행 제한이 해제되면 DEADZONE을 준비한다. 수정한 DEADZONE Worker에서 공동 차량을 생성한다. 서버 시뮬레이션에서 참가자는 같은 차량에 붙어 이동하고 피격 피해를 공동 체력으로 받는다.
4. 차량이 손상된 웨이브 사이에 Pleos 화면의 ‘보급품 1개로 차량 수리’를 누른다. 수리는 최대 60 HP를 회복한다. 파티 서버가 먼저 보급품을 예약하고, 경기 서버의 동일 실행·웨이브 영수증을 받아 확정한다. 명시적 거절은 보급품을 돌려주고, 응답이 끊긴 경우 같은 수리 요청을 재시도한다.

수정한 Worker 원본은 `C:/Users/jeff4/Projects/Z-RIDE-DEADZONE`에 있다. Z-RIDE 서버의 `ZRIDE_DEADZONE_ORIGIN`을 해당 Worker 주소로 설정한다. 실제 로컬 Worker를 사용한 재현은 `DEADZONE_ROOT`와 `DEADZONE_ORIGIN`을 설정하고 `node server/tools/route-repair-live.mjs`를 실행한다. 이 재현은 Git 장소 카탈로그, 테스트 차량 신호, 자동화 폰을 사용한다.

기존 목록에서 방문 게임을 열 장소는 접근·주차·체류가 검토된 스팟으로 제한한다. 실제 충전소용 전기도둑·충전 릴레이, 주유소·주차장의 게임 배정과 아이템 소비는 각 게임의 규칙 및 입장 권한을 연결하는 후속 범위다. 현재 보급품 사용처는 DEADZONE 수리다.


검증에서는 QR 초대와 계정 승인을 거쳐 기존 장소 카탈로그의 수집 구간에서 보급품 1개를 얻고, 중복 요청으로 재고가 늘지 않음을 확인했다. 실제 로컬 DEADZONE Worker에서 체력 255 → 300, 보급품 1 → 0을 확인했다. 별도의 Pleos 에뮬레이터 시험에서도 테스트 보급품을 넣은 파티로 차량 화면의 수리 버튼을 눌러 같은 결과를 확인했다. 에뮬레이터의 D 신호가 유지되지 않아 이동 중 수집부터 동일 장치에서 연속 재현하는 시험은 완료하지 못했다. 폰은 자동화 클라이언트였다.
