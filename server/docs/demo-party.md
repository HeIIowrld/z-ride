# 실제 API로 관제 시연용 TEST 파티 만들기

서버가 실행 중일 때 `server/` 디렉터리에서:

```sh
node tools/demo-party.mjs --base http://127.0.0.1:8001
```

자동 종료 시험은 `--durationsec 30`을 추가한다. 0 또는 생략이면 SIGINT/Ctrl+C까지 유지한다. `--base`에는 컨테이너의 실제 HTTP(S) origin도 지정할 수 있다.

이 도구는 **실제 REST와 WebSocket**으로 새 방 하나와 CAR_HOST 1명·각 좌석 PHONE 3명을 만든다. 참가 코드를 매번 갱신하고 호스트 승인을 거친다. 각 폰이 좌표 없는 DEMO_PICKUP_A/B/C를 각각 수집해 보급 3개를 모은 뒤, 차량 지원이 1개 소비하고 세 폰이 자기 영역의 좀비를 한 번씩 공격한다. 호스트는 2초마다 허용된 주차 신호를 보고한다.

모든 닉네임에 TEST를 넣고 차량 신호 source는 `SIMULATED_API_CLIENTS`로 표시한다. 실제 SDK·GPS·실차 신호를 읽은 결과가 아니다. 브라우저의 가짜 상태를 만드는 방식도 아니다. 관제 화면은 서버가 확정한 상태를 구독한다.

표준 출력은 방 ID·참가자·simulated 표지만 제공하고 **세션 토큰·참가 코드는 출력하지 않는다.** 관제는 별도로 설정한 읽기 전용 운영자 토큰으로 `/observer`에 접속해 해당 방을 선택한다. 이 도구가 운영자 토큰을 필요로 하거나 생성하는 것은 아니다.

기존 방을 바꾸지 않고 매 실행마다 새 TEST 방을 만든다. 종료하면 소켓과 보고가 끊겨 공동 전투가 pause한다. DB가 켜져 있으면 TEST 방과 확정 재고도 보존되며, 도구 종료가 방 삭제를 뜻하지 않는다. 재실행은 같은 파티 재접속이 아닌 별도 파티 생성이다.
